Disaster recovery
Backups are AES-256-GCM encrypted with APP_MASTER_KEY. Keep the backup file and master key separately.
Restore replaces the local Stream24 database. Workers may need to reconnect if their tokens differ from the backup.



Setup checklist
Production readiness without editing configuration files by hand.
One-click Windows setup
From an extracted Stream24 folder, run:
powershell -ExecutionPolicy Bypass -File .\scripts\windows\setup-stream24.ps1 -Mode Both -InstallStartupTasks
For a second worker PC, create its worker token first, then use -Mode Worker -ServerUrl http://SERVER-PC:3000 -AgentToken TOKEN.
Update channel
Update checks are disabled unless STREAM24_UPDATE_MANIFEST_URL is configured. Stream24 never installs an update silently.
Apply a verified update
powershell -ExecutionPolicy Bypass -File .\scripts\windows\update-stream24.ps1 -Package "UPDATE_ZIP_OR_URL" -Sha256 "EXPECTED_SHA256"
The updater verifies SHA-256, keeps a rollback copy, and restarts Stream24 startup tasks.
Diagnostics
powershell -ExecutionPolicy Bypass -File .\scripts\windows\stream24-doctor.ps1
