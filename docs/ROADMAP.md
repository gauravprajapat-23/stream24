# Stream24 Roadmap

## Completed
- Phase 1: local control plane, encrypted RTMP keys, Windows FFmpeg worker
- Phase 2: playlists, FFprobe preflight, restart recovery, worker autostart
- Phase 3: schedules, stream editing, skip/restart controls, live logs, normalization

## Phase 4
- User authentication and multi-user ownership
- Normalized media catalog/cache with source fingerprints
- More seamless continuous playlist handoff
- Stream/session analytics and uptime history
- Schedule exception dates and one-time schedules
- Better worker capacity/health metrics
- Remote deployment of the lightweight control plane using free/no-card-compatible options where available

## Later
- YouTube OAuth/API integration
- Multi-destination RTMP
- Android worker research
- Paid cloud-worker option without changing the local-worker architecture

- Phase 11: Automatic media sync, checksum catalog, progress and storage management — COMPLETE
